The Russian-Learning-App is a "multipurpose" Vocabulary-Trainer that uses WinForms, .NET-10 Framework and LINQ to create learning files able to be edited or be training knowledge with.

The Russian-Keyboard provided to write entries is able to be used outside the program and can thus be seen and used as a Windows On-Screen-Keyboard for russian letters.

To use the program, create a learning file and add word pairs with the entry adding mechanic, or use the already existing learning files inside the project folder to begin learning russian.
After loading the learning file you can edit entries or set session-parameters to create a learning instance of your liking. (The current setups does not allow timers to be set)
Start a learning instance by clicking the corresponding button and begin writing the german or russian equvalent of the word being shown.
